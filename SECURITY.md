# Security Policy

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue. Contact the project maintainers through the private security-reporting mechanism configured for the repository.

Include the affected component, a concise reproduction, impact, and any suggested mitigation. Do not include passwords, private athlete data, access tokens, or other secrets.

## Data security

OTRI should minimize personal data collection and should never commit secrets or private athlete data to the repository.
