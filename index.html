01 / WHY OTRI

Same distance.
Different challenge.

A 50 km race can be fast and runnable, or steep, technical and mountainous. A finish time does not describe the whole performance.

OTRI is designed to create a common performance signal by considering the race and its course — making comparisons more meaningful across events.

Distance is similar. The course is not. OTRI is built to account for that context.

04 / FOR ORGANIZERS

Give us the results.
We handle the index.

NO SCORE TO ENTER

OTRI is being built around a straightforward organizer workflow: provide race details, upload official results, validate the data and submit.

  • One participant per row
  • Finish time and ranking
  • Race distance and elevation
  • GPX/course data where available
  • OTRI calculates the index — organizers do not enter a score

05 / THE OTRI STANDARD

Open by design.
Not a black box.

These are not marketing labels. They describe how OTRI is intended to be built and evaluated.

OPENSource code and methodology are public.
TRANSPARENTScores can be inspected and explained.
REPRODUCIBLEThe same inputs and scoring version produce the same result.
TRACEABLEDatasets record provenance and permissions.
PRIVACY-CONSCIOUSCollect and publish only what is necessary.
INDEPENDENTOTRI develops its own methodology and data infrastructure.
