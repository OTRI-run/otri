OPEN / TRANSPARENTOTRITRAIL PERFORMANCE
01 / WHAT WE’RE BUILDING

A shared, open foundation for trail performance.

Trail races are wildly different. A 50 km course can mean a fast runnable route or a brutal mountain day. OTRI is designed to turn official race results and course data into a consistent performance signal.

The methodology, validation rules and software are designed to be inspectable and reproducible — not a black box.

02 / HOW IT WORKS
01

Official results

Organizers upload race results in a familiar XLSX/CSV format.

02

Validation

Results, race metadata and provenance are checked before scoring.

03

Course analysis

Distance, elevation and course characteristics become part of the model.

04

OTRI model

An independent scoring engine converts performance into an OTRI score.

05

Open outputs

Scores can power profiles, rankings, analytics and eventually an API.

03 / FOR ORGANIZERS

Already have a results spreadsheet?
That’s the point.

OTRI is being designed around an organizer workflow that feels familiar: create a race, provide the course metadata, upload the official results, validate, submit.

  • One result file per race
  • One participant per row
  • Finish time and ranking for finishers
  • Race distance and elevation data
  • GPX/course information where available
  • OTRI calculates the score — organizers never enter it

INDEPENDENCE
OTRI

Built independently.

OTRI is an independent open-source project. It is not affiliated with ITRA, UTMB, or another commercial trail-running ranking organization. OTRI will build its own methodology and use legitimately obtained data.
