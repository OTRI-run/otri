01 / WHY OTRI

One number should
mean more.

A 50 km race can be fast and runnable, or steep, technical and mountainous. Distance and time are only part of the performance.

OTRI aims to provide a common performance signal by taking the race and its course into account — so athletes can compare performances across different events more meaningfully.

01

Compare across races

Put performances from different courses into a common index instead of relying only on finishing place or raw time.

04 / FOR ORGANIZERS

Already have the results?
Start there.

NO SCORE TO ENTER

OTRI is being built around a straightforward organizer workflow: provide race details, upload the official results, validate the data and submit.

  • One participant per row
  • Finish time and ranking
  • Race distance and elevation
  • GPX/course data where available
  • OTRI calculates the index — organizers do not enter a score
