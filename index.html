01 / WHY OTRI

A common language for trail performance.

Trail races are not directly comparable. A fast 50 km course and a technical mountain 50 km can demand completely different performances. OTRI is designed to look beyond finishing place and raw time by considering the course itself.

The aim is simple: create an independent performance index that athletes can understand, organizers can feed with official results, and developers can build on.

OTRI is designed to be transparent rather than a black box. The methodology, inputs, assumptions and validation rules should be visible, testable and reproducible.

03 / FOR ORGANIZERS

Already have a results spreadsheet?
That’s the point.

OTRI is being designed around an organizer workflow that feels familiar: create a race, provide the course metadata, upload the official results, validate, submit.

  • One result file per race
  • One participant per row
  • Finish time and ranking for finishers
  • Race distance and elevation data
  • GPX/course information where available
  • OTRI calculates the score — organizers never enter it

OTRI is an independent open-source project. It is not affiliated with ITRA, UTMB, or another commercial trail-running ranking organization. OTRI will build its own methodology and use legitimately obtained data.
