# OTRI documentation

This directory contains technical, methodology, data, governance, API, and operational documentation.

## Sections

- `roadmap.md` — step-by-step development roadmap, in PR-sized chunks
- `architecture/` — system and repository architecture
- `methodology/` — scoring and statistical research
- `data/` — schemas, provenance, validation, and data lifecycle
- `governance/` — project governance and decision records
- `api/` — future API contracts and reference documentation
- `operations/` — deployment, maintenance, and operational runbooks (see [`operations/digitalocean-deployment.md`](operations/digitalocean-deployment.md) for the API's production deployment guide)
