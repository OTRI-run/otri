# OTRI documentation

This directory contains technical, methodology, data, governance, product UX, research, API, and operational documentation.

## Sections

- `roadmap.md` — step-by-step development roadmap, in PR-sized chunks
- `AI_PRODUCT_IMPLEMENTATION_BRIEF.md` — master implementation brief for another AI/developer; read this before implementing the new runner/organizer UX
- `product/organizer-onboarding.md` — detailed organizer account → organization → event → race → course → results → validation → review → publication workflow
- `product/pre-race-score-calculator.md` — detailed runner pre-race score calculator and analysis experience
- `methodology/` — scoring and statistical research
- `methodology/overall-runner-index.md` — proposed rolling overall OTRI Index and rules for which race scores count
- `research/platform-product-patterns.md` — research on organizer, race, scoring, and index product patterns and how OTRI should adapt useful patterns independently
- `architecture/` — system and repository architecture
- `data/` — schemas, provenance, validation, and data lifecycle
- `governance/` — project governance and decision records
- `api/` — future API contracts and reference documentation
- `operations/` — deployment, maintenance, and operational runbooks (see [`operations/digitalocean-deployment.md`](operations/digitalocean-deployment.md) for the API's production deployment guide)
