OTRI — Open Trail Running Index

Geometric wordmark / Field identity.
Use the full wordmark when introducing OTRI. The closed O symbol is for places where the name is already known.
Do not stretch, recolour, obscure the O, or imply that OTRI approves/certifies a race.
Ink #23231F; signal red #BD3924; sand #DBBA89; light #F4F1E8.
