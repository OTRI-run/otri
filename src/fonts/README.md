# Fonts

`archivo-black-latin.woff2` — Archivo Black, latin subset, from Google Fonts.

Licensed under the SIL Open Font License 1.1: https://openfontlicense.org
Upstream: https://github.com/googlefonts/archivo

It is used for one thing only, the OTRI wordmark, so that the letters on the site and the letters
in the downloadable brand files are the same shapes. `scripts/build_badge.py` outlines the
same font to build those files, which is why they need no font to render.
